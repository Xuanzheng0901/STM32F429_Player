# 电池检测

`battery_init(callback)` 只在启动时调用一次，位于 `UI_init()` 之后。
模块独占已有 ADC1/PB1（IN9），电池电压经二分之一分压后接入。
12 位 ADC、480 周期采样时间沿用 CubeMX 配置，不使用 DMA 或 ADC 中断。

低优先级任务启动后立即采样，此后每 5 秒采样一次。每轮读取 16 次取平均，
按 `电池 mV = ADC平均值 × 3300 × 2 / 4095` 换算，使用整数并四舍五入。
参考电压 `BATTERY_REFERENCE_MV` 默认 3300 mV；若实测 VDDA 有偏差，修改此常量。
读取失败时停止 ADC、记录警告，保留上一轮显示，下个周期重试。

任务静态栈为 512 words（ARM 上 2048 B），连同 TCB 放在普通 SRAM，
不占用 FreeRTOS 动态堆。模块只通过回调发布 mV 和 0～100 的百分比，
不依赖播放器或 LVGL。应用将回调连接到 `UI_set_battery()`，由 UI 加锁更新
底栏电压（0.01 V）、百分比和电池填充条。采样前显示占位符和空电池。

## 电压—电量表

采用 [Analog Devices：Characterizing a Lithium-Ion (Li+) Cell for Use with an
Open-Circuit-Voltage (OCV) Based Fuel Gauge，表 1](https://www.analog.com/en/resources/design-notes/characterizing-a-lithiumion-li-cell-for-use-with-an-opencircuitvoltage-ocv-based-fuel-gauge.html)
的典型单节锂电池数据，电压四舍五入到 mV，节点间线性插值。

| 电量 | mV | 电量 | mV | 电量 | mV |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 0% | 3306 | 35% | 3784 | 70% | 3945 |
| 5% | 3675 | 40% | 3793 | 75% | 3975 |
| 10% | 3687 | 45% | 3806 | 80% | 4008 |
| 15% | 3710 | 50% | 3821 | 85% | 4045 |
| 20% | 3741 | 55% | 3841 | 90% | 4086 |
| 25% | 3762 | 60% | 3884 | 95% | 4129 |
| 30% | 3775 | 65% | 3918 | 100% | 4177 |

低于首节点返回 0%，高于末节点返回 100%，因此 4.2 V 显示 100%。
该表来自静置后的开路电压，当前设备在播放/充电期间测得的是端电压，
加之电芯、温度和老化差异，百分比仅作近似显示，不是库仑计，也不用于关机保护。
需要更准确的电量时，可用实际电芯数据替换此表。

主机测试验证换算、取平均、所有节点/全范围单调性、ADC 失败不发布及下一周期恢复，
并检查任务周期为 5 秒。实测 ADC 电压精度和任务栈余量仍需上板确认。
